# SA House Electricals — GitHub Pages

## Upload to GitHub (Android)

1. Create a **Public** GitHub repository named `sa-house-electricals`.
2. Tap **Add file → Upload files**.
3. Select **ALL files in this folder** (including `index.html` and all image files).
4. Make sure `index.html` is visible directly in the repository — not inside another folder.
5. Tap **Commit changes**.
6. Go to **Settings → Pages**.
7. Set **Source** to `Deploy from a branch`.
8. Set **Branch** to `main` and folder to `/ (root)`.
9. Tap **Save**.
10. Your site will appear at:
   `https://YOUR-GITHUB-USERNAME.github.io/sa-house-electricals/`
